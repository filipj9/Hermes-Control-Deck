# Assets

The author states that the original Hermes Control UI artwork was generated
from scratch specifically for this project and was not copied from other apps
or repositories.

The repository contains UI frames, keycaps, knobs, PWA icons, splash images,
`codex-logo.svg` and `hermes-logo.png` under `apps/web/assets/`. A release
inventory must list every file and checksum before publication.

Frames, controls, glow layers and layout artwork are project UI assets under the
author's statement. Logos and marks that identify OpenAI/Codex, Hermes or Nous
Research are not claimed as project-owned trademarks. Their owners' brand and
redistribution policies still apply.

Hermes Control is independent and is not officially endorsed, sponsored or
affiliated with OpenAI, Codex, Nous Research or Hermes.
